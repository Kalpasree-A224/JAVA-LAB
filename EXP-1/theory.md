# Experiment 1: Arrays and Searching

These programs store integer data in arrays, traverse the elements, sort values, and locate a value in sorted data. Array indices start at zero; `Arrays.binarySearch` returns a negative result when the target is absent.

## Programs

- `AscendingOrder.java`: sorts an integer array in ascending order.
- `BinarySearch.java`: searches a sorted array.
- `LargestSmallest.java`: finds the minimum and maximum in one traversal.
- `MarksAbvsixty.java` and `printmarksabove.java`: filter marks greater than 60.

Compile and run from this directory, for example:

```bash
javac AscendingOrder.java
java AscendingOrder
```
