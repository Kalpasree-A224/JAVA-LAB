# Experiment 10: AWT Applets

These legacy examples extend `java.applet.Applet` and draw with AWT or compose AWT components. They demonstrate graphics, a `CardLayout`, a `GridLayout`, and event handling. Applets are obsolete: the browser plugin and `appletviewer` are unavailable in modern JDKs. Compile the sources with a JDK that still includes the applet API; run them only in a compatible legacy applet viewer or container.
